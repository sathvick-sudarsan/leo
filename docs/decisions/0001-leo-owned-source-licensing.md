# 0001 — Leo-owned source licensing

Status: Accepted by owner — 2026-09-04

The repository remains public. Leo-owned source is all-rights-reserved for now, using the approved wording in the root `LICENSE`. Do not add MIT, Apache, GPL, or another generic open-source license to Leo-owned source. Public visibility does not grant copying, modification, redistribution, or commercial-use permission.

Runtime/build dependencies retain their own licenses; PySide6/Qt licensing is separate from Leo's source license. No third-party source is copied/adapted in M0, including Clicky/ClickyWin. Record future copying/adaptation and required upstream notices in `THIRD_PARTY_NOTICES.md` in the same change.

M0 approves local development packages only, not a public binary release. Public binary distribution requires a dependency-license/notice compliance review. This decision preserves the owner's future licensing choice without changing dependency terms.
