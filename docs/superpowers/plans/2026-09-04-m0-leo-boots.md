# M0 — Leo Boots Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create the smallest stable Windows Leo desktop chassis that boots, lives in the system tray, detects whether DaVinci Resolve is foregrounded, can render a basic non-interactive overlay, passes automated verification, and produces a Windows packaging smoke build.

**Architecture:** Leo is a Python 3.12 + PySide6 Windows desktop application with product-owned boundaries from the first commit. M0 contains only the companion shell and infrastructure needed to support M1; Resolve detection is isolated behind a focused Windows adapter, overlay rendering is isolated behind its own UI component, and packaging/CI are kept minimal. No speech, VLM, screenshot capture, pointer grounding, Resolve scripting, MCP, RAG, or copilot behavior belongs in M0.

**Tech Stack:** Python 3.12, PySide6, uv, pytest, pytest-qt, Ruff, PyInstaller, GitHub Actions, Windows `ctypes` APIs.

**Spec:** `docs/superpowers/specs/2026-09-04-leo-development-operating-model-design.md`

## Global Constraints

- Target platform for M0: Windows 11.
- Python version: `>=3.12,<3.13`.
- Package/dependency manager: `uv`.
- GUI toolkit: PySide6.
- `main` must remain runnable after every merged task/PR.
- M0 must not add speech, screenshot capture, multimodal models, pointer grounding, Resolve scripting/MCP, knowledge retrieval, or copilot actions.
- Third-party code may be adapted only when required for the current slice and must retain required attribution.
- Prefer standard-library Windows calls for foreground-process detection before adding another runtime dependency.
- Tests are necessary; final M0 acceptance also requires a real Windows/Resolve dogfood smoke test.

# src/leo/windows/foreground_app.py
from __future__ import annotations

from dataclasses import dataclass
from pathlib import PureWindowsPath


@dataclass(frozen=True, slots=True)
class ForegroundApp:
    hwnd: int
    pid: int
    executable: str | None
    title: str


def is_davinci_resolve(app: ForegroundApp | None) -> bool:
    if app is None or not app.executable:
        return False
    return PureWindowsPath(app.executable).name.casefold() == "resolve.exe"

import ctypes
from ctypes import wintypes

PROCESS_QUERY_LIMITED_INFORMATION = 0x1000

_user32 = ctypes.WinDLL("user32", use_last_error=True)
_kernel32 = ctypes.WinDLL("kernel32", use_last_error=True)


def _get_foreground_hwnd() -> int:
    return int(_user32.GetForegroundWindow())


def _get_window_pid(hwnd: int) -> int:
    pid = wintypes.DWORD()
    _user32.GetWindowThreadProcessId(wintypes.HWND(hwnd), ctypes.byref(pid))
    return int(pid.value)


def _get_window_title(hwnd: int) -> str:
    length = int(_user32.GetWindowTextLengthW(wintypes.HWND(hwnd)))
    if length <= 0:
        return ""
    buffer = ctypes.create_unicode_buffer(length + 1)
    _user32.GetWindowTextW(wintypes.HWND(hwnd), buffer, len(buffer))
    return buffer.value


def _get_process_executable(pid: int) -> str | None:
    handle = _kernel32.OpenProcess(PROCESS_QUERY_LIMITED_INFORMATION, False, pid)
    if not handle:
        return None
    try:
        size = wintypes.DWORD(32768)
        buffer = ctypes.create_unicode_buffer(size.value)
        if not _kernel32.QueryFullProcessImageNameW(handle, 0, buffer, ctypes.byref(size)):
            return None
        return buffer.value
    finally:
        _kernel32.CloseHandle(handle)


def get_foreground_app() -> ForegroundApp | None:
    hwnd = _get_foreground_hwnd()
    if not hwnd:
        return None
    pid = _get_window_pid(hwnd)
    return ForegroundApp(
        hwnd=hwnd,
        pid=pid,
        executable=_get_process_executable(pid),
        title=_get_window_title(hwnd),
    )
```

# src/leo/tray.py
from __future__ import annotations

from collections.abc import Callable

from PySide6.QtCore import QTimer
from PySide6.QtGui import QAction
from PySide6.QtWidgets import QApplication, QMenu, QStyle, QSystemTrayIcon

from leo.windows.foreground_app import ForegroundApp, get_foreground_app, is_davinci_resolve

ForegroundProvider = Callable[[], ForegroundApp | None]


class LeoTray(QSystemTrayIcon):
    def __init__(self, foreground_provider: ForegroundProvider = get_foreground_app) -> None:
        icon = QApplication.style().standardIcon(QStyle.StandardPixmap.SP_ComputerIcon)
        super().__init__(icon)
        self._foreground_provider = foreground_provider

        menu = QMenu()
        self.status_action = QAction("Resolve: inactive", menu)
        self.status_action.setEnabled(False)
        menu.addAction(self.status_action)
        menu.addSeparator()

        quit_action = QAction("Quit Leo", menu)
        quit_action.triggered.connect(QApplication.instance().quit)
        menu.addAction(quit_action)
        self.setContextMenu(menu)

        self._timer = QTimer(self)
        self._timer.setInterval(500)
        self._timer.timeout.connect(self.refresh_status)
        self._timer.start()
        self.refresh_status()

    def refresh_status(self) -> None:
        active = is_davinci_resolve(self._foreground_provider())
        self.status_action.setText("Resolve: active" if active else "Resolve: inactive")
```

from __future__ import annotations

from PySide6.QtCore import Qt
from PySide6.QtWidgets import QLabel, QVBoxLayout, QWidget


class LeoOverlay(QWidget):
    def __init__(self) -> None:
        super().__init__()
        self.setWindowFlags(
            Qt.WindowType.Tool
            | Qt.WindowType.FramelessWindowHint
            | Qt.WindowType.WindowStaysOnTopHint
            | Qt.WindowType.WindowTransparentForInput
        )
        self.setAttribute(Qt.WidgetAttribute.WA_TranslucentBackground, True)
        self.setAttribute(Qt.WidgetAttribute.WA_ShowWithoutActivating, True)

        self.label = QLabel("")
        layout = QVBoxLayout(self)
        layout.setContentsMargins(12, 8, 12, 8)
        layout.addWidget(self.label)
        self.hide()

    def show_status(self, text: str) -> None:
        self.label.setText(text)
        self.adjustSize()
        self.show()

    def clear_status(self) -> None:
        self.label.clear()
        self.hide()
```

# Windows Companion Architecture — M0

## Responsibilities
- `leo.app`: owns QApplication lifecycle and composes long-lived UI objects.
- `leo.tray`: owns tray status and quitting Leo.
- `leo.overlay`: owns non-interactive on-screen status rendering.
- `leo.windows.foreground_app`: owns foreground-window/process inspection and Resolve classification.

## Boundaries
M0 has no model clients, audio, screen capture, Resolve API/MCP, retrieval, or action execution.

## Invariants
- Closing/no visible overlay window must not terminate Leo.
- Overlay must not steal input focus.
- Resolve detection is based on `Resolve.exe`, not window-title guessing.
- `main` remains directly runnable with `uv run python -m leo`.
```
